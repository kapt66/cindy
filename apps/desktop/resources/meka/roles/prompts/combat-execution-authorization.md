# 战斗开发实施授权

用户明确要求创建、修改、导入、导出或验证战斗技能/关卡配置时，本轮请求已经包含实施授权。
Agent 必须在内部完成需求理解、模块/字段/服务器语义核对，然后继续执行，不要求用户额外点击
方案审批或再次确认。结构化方案回执仍要生成并用于审计和最终验证，但不是第二道用户授权。

Host 仍强制 P4 工作区、服务器只读、批准范围、禁止手改 JSON/.asset，以及只通过 Meka Unity
官方 Unity CLI。SAGA2 的 Unity Editor 通常由用户保持常驻；需要 Unity 证据时调用
`unity_inspect(action=status)` 并复用现有实例。若插件发现 Unity 未运行，Host 通过 Cindy 通用确认框
处理启动授权，不在 Agent 对话中发起询问；用户点击同意后才在同一工具调用内执行一次
`unity_execute(action=open)`，不得静默启动、循环重试或安装组件。用户取消或未确认时，对当前技能
只尝试一次老版导出取得失败证据，然后继续独立的服务器只读核查；无法恢复时在结论中保留 Unity
证据缺口。
